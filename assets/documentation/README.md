# Advanced Dirt Removal 2.0 screenshots

These are unedited screenshots of Resolve Studio 21.1.1.10 on macOS, captured
after installing the 2.0.0 macOS package into the system OFX folder.

- `resolve-2.0-controls.png`: Restored view and the current control groups.
- `resolve-2.0-red-difference.png`: Red Difference and its view options.

The viewer uses the engine benchmark's deterministic synthetic generator:
seed 11, 512 × 512, 21 frames, frame index 5. It contains generated texture and
temporary specks; it is an interface demonstration, not a film restoration
quality claim. No private footage, model training material or machine paths
are shown. The preceding installed-plugin render was byte-identical to the
engine reference; Red Difference matched its expected pixels exactly.

The older 1.x assets remain in `assets/images` for historical documentation;
the current README uses only the 2.0 screenshots above.
